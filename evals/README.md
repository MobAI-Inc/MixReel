# Evals

These cases describe how an agent using the skills should behave on an ad brief. They are not a scoreboard and they do not include a past run.

Run a case by handing the agent the brief and the skill path, with no expected answer in the prompt. Compare the script and the plan with the checks in the case. Do not call a paid API as part of the case unless the person running it has said so.

Add a case when a review rule changes. Do not paste a client brief.
