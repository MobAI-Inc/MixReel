# Analyze a reference ad

Pipeline stage 1. The map is [pipeline](../mixreel/references/pipeline.md). You are extracting evidence, not cloning the film.

## When

Use this when the user supplies a reference video or a music track. With no reference, this stage has nothing to do. Say so in one line and carry on with [script](../mixreel-script/SKILL.md), or with whatever else the user asked for. Skipping this stage does not end the job. Do not invent timings, and do not go looking for someone else's ad. If the user asked for nothing but an analysis and gave you no file, ask for the file.

## Output

`reference-analysis.md` with timestamps, what you could actually watch or hear, and the dimensions worth borrowing. Borrow structure. Do not copy footage, music, packaging, or words.

## Must follow

- Start by finding the project and its brand layer, as [project](../mixreel/references/project.md) describes, and follow `brand/requirements.md` when it exists.
- Watch and listen when you can. A frame sample is a frame sample. A silent pass is a silent pass.
- Follow [frame reading](../mixreel/references/frame-reading.md) for every contact sheet and every extracted frame.
- Product claims in the reference are not facts about the user's product. Facts come from the advertiser.
- Run the scripts in [analysis scripts](references/analyze-tools.md) before you describe cuts, loudness, or motion.
