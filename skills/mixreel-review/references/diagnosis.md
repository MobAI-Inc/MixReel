# Diagnosis

Find the earliest stage that introduced the defect. Change only that.

| Cause | Stage to reopen |
| --- | --- |
| Wrong claim, missing product, wrong action | Script |
| Wrong frame, broken package, identity drift in a still | Keyframes |
| Wrong grouping, prompt, or reference binding | Video plan |
| Bad motion inside an otherwise approved prompt | Produce, that shot only |
| Late cut, level, caption timing | Produce, the edit |

Carry a passed image forward only when it passed and its requirements and references are unchanged. A pixel diff cannot approve a failed or unreviewed image. A repair that does not change the image stays failed.

After the repair, compare the change and the regions that should have stayed still. If the result is not better, revise the diagnosis before another paid attempt.

Do not close a review by switching vendor, adding an extra paid try, or rewriting the script. Those are new user decisions.

A review-only request stops at the recommendation.
