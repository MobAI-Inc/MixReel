# Brand marks stay exact

This is the only statement of how logos, packaging text, product copy, and app UI are kept.

Those elements must match the real asset. Prefer the asset, or an overlay composited in the edit, over a mark a model draws. Do not assume a model will reproduce a logo, a package line, or a UI. Keep the obligation in the script and in the cut even when a prompt excludes the mark. Do not delete the mark from the script to make a prompt easier, and do not claim the model rendered it faithfully.

Check the marks against the asset on every keyframe and in the finished film. A generated approximation is a failure.

For how UI is taken from the product's own files, read [product, copy, and UI on screen](../../mixreel-script/references/ad-script.md). This file does not replace that section.
