# Brand marks stay exact

This is the only statement of how logos, packaging text, product copy, and app UI are kept. Other files link here.

Client logos, packaging text, product copy, and app UI must match the real client asset exactly. Prefer that asset, or an overlay composited in the edit, over a mark an image or video model draws. Do not assume a model will reproduce exact UI, brand marks, packaging text, or typography. Keep the obligation in the script and in the cut even when a model prompt excludes those marks. Do not delete them from the script to make a prompt easier, and do not claim the model rendered them faithfully.

Check the marks against the asset on every keyframe and in the finished film. A generated approximation is a failure.

When you are writing or reviewing a script, how the UI is taken from the product's own files is in [product, copy, and UI on screen](../../mixreel-script/references/ad-script.md#product-copy-and-ui-on-screen). Read that section then. This file does not replace it.
