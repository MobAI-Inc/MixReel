# Handoffs

Reuse an artifact when it still matches the current brief.

An artifact is adequate when all of these are true:

- The user accepted it, or an earlier step recorded it as accepted, and the brief has not changed in a way that affects it.
- Its inputs are still the inputs you would use now.
- A later defect has not been traced back to it.

Do not rerun a stage to make the folder look complete. Do not carry a rejected file forward because it is convenient.

When you cross a stage, name the file you are relying on and the decision it encodes. If that decision is missing, stop and ask, or produce the missing artifact if the user already authorized that stage.

A keyframe that passed can be reused only when the shot requirements and the references are unchanged. A pixel diff does not approve an image that failed or was never reviewed. A repair that does not change the pixels stays failed.

Paid work uses the same project journal. Do not open a second ledger for the same budget.
