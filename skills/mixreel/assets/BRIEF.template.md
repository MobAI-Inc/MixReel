# Project brief

## Request

Deliverable, audience, length, aspect ratio, channel, and the step the user has authorized. State the current stop point.

## Sources

Reference videos, music, product photos, screen recordings, and logo or package files. For each file record what it is allowed to contribute (hook, pacing, camera, product truth, voice) and what it must not contribute. Keep keys and signed URLs out.

## Message

Link `brand/brand-context.md`. Record the one message this film carries, the claim limits, the desired action, and any required on-screen copy. Product facts stay in the brand file.

## Borrowing

For each borrowed dimension: source time, keep / adapt / exclude, and why. Borrow structure. Do not copy someone else's footage, music, packaging, or words.

## Decisions

Provider and model id, previs yes or no, which shots are generated versus a real recording, new keyframes versus reused assets, and duration and cost as quoted, estimated, or unknown.

## Reviews and budget

For each review: artifact, decision (pass, fail, not checked), and evidence. Record currency, ceiling, and retry limit. Separate a delegated choice from a user approval.
