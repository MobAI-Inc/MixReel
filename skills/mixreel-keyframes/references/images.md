# Images

For each new keyframe record:

- the composition source and why it was the one source
- style references, if any
- the product or person reference, and what it is allowed to constrain
- the provider and model id that actually ran
- the prompt and the ordered inputs that were sent

`reference-sheet.jpg` in the film folder, when there is one, shows which real file supports which shot. Send the real file as the input, never the sheet.

A style reference is not a license to copy a third party's product or face.

Local repair changes the region that failed. Compare the result, including regions that should have stayed still. If the repair does not improve the defect, stop and reread [diagnosis](../../mixreel-review/references/diagnosis.md) before you pay again.

Do not switch providers to make a review comment go away. A provider change is a user decision.
