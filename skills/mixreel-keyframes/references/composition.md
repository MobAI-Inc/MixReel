# Composition source

Each new keyframe has one composition source.

Prefer, in order:

1. A previs still for that shot, when camera or blocking was the risk.
2. A frame from the user's own reference, when they asked to borrow the composition.
3. A product photo or screen capture the user supplied.

The source is a guide for framing. It is not pasted into the finished ad unless the user said the real photo is the frame.

Do not download reference images from a gallery, a search result, or a social network as part of this skill. If the user does not have a source, ask, or block a rough previs and use that.
