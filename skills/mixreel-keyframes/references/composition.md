# Composition source

Read this when a new keyframe has no [previs](../../mixreel-script/references/previs.md) render and no frame you already know fits. If a previs render exists, use that and stop reading here. It supplies layout only. Its proxy colours and body shapes must not appear in the image.

Write the shot's scale, subject count and how much of the frame they fill, the foreground and background relationship, and the action that must stay visible. Then pick one source, preferring, in order:

1. A previs still for that shot, when camera or blocking was the risk.
2. A frame from the user's own reference, at the matching shot, when they asked to borrow the composition.
3. A product photo or screen capture the user supplied.

Do not download reference images from a gallery, a search result, or a social network as part of this skill. If the user does not have a source, ask, or block a rough previs and use that. Keep an unresolved shot incomplete when no source fits.

Select exactly one composition source for each new keyframe. Record the previs shot, the file or source-video time, the borrowed composition, and the required changes. Show all selected sources together to check for repeated scale and angles. The source is a guide for framing. It is not pasted into the finished ad unless the user said the real photo is the frame.

A reference-video frame supplies composition and style only when the user chose the reference's style. Otherwise it supplies composition only, and the user's chosen style references supply the style. In that case, check the output for unwanted style coming from the frame.
