# Shot list

Fill every column of the shot table in [the template](../assets/SCRIPT.template.md). Write `none` where a shot has no copy or no spoken line, so a blank never means undecided.

When a previs is used, also write positions and facing so the scene file can be built. A locked-off pack shot or a supplied screen recording does not need a walking path.

Do not deliver a timed paragraph in place of shots. Provider prompts are a later stage. Leave them empty here.

## Early feasibility

Note duration, which shots are generated, which are a real recording, and any limit you have already verified from the provider's own docs. Unknown limits stay unknown. Do not quote a price you have not been given.

## Reference sheet

When the project has real images for these shots, lay them out in one `reference-sheet.jpg` in the film folder, with Pillow or ffmpeg. Use frames from `brand/taste-library/` and files from `brand/assets/`, each labelled with its shot id and source file. Nothing on the sheet is generated, so this does not break the rule about showing the script before any illustration. When the project has no such images, skip the sheet.

Read [previs](previs.md) if the camera or the hands can hide the product.
