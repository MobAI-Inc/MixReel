# Borrow structure, not content

A reference can lend a hook shape, a pacing pattern, a camera move, or a music relationship. It cannot lend its footage, its track, its performer, its package, or its claims.

For each dimension write keep, adapt, or exclude, with the source time. Unselected dimensions do not quietly control the new film.

A reference is a file the user supplied for this film, or an ad they picked from `brand/taste-library/`. With neither, skip this file. Do not search for someone else's ad to imitate.
