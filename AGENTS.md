# Repository notes for agents

This is the public MixReel repository published by MobAI Inc. Work you do
here is for that public tree.

- Follow `LICENSE` and the contributor agreement in `CONTRIBUTING.md`.
- Do not add private hosts, private product names, customer assets, or a
  relay in front of a model vendor.
- Model names and API keys come from the user's environment and config.
- Ad and product video is the scope. Do not add a story mode.
- Keep new skill references linked from a `SKILL.md`, and keep each
  `SKILL.md` under 150 lines.
- Run the unit tests and `python3 scripts/check_package.py` before handing work back.
